Illusion

Prism

Prism applies UCA duality constraints to the eigenvalue structure of complex networks. Where random matrix theory gives universal statistics, Prism gives system-specific structural bounds by enforcing self-consistency under duality conjugation.

Core capability: given a network, Prism computes how much its spectrum must shift to satisfy UCA duality. Networks with small shifts are structurally self-consistent; large shifts indicate asymmetric features that violate duality.

$ prism demo
  Prism Demo: Zachary's Karate Club (34 nodes, 78 edges)

  PRISM SPECTRAL ANALYSIS
  Network: 34 nodes
  Duality defect (original):    16.733201
  Duality defect (constrained): 0.00e+00
  Spectral RMSE (shift):        0.562236
  Max eigenvalue shift:         1.529174
  Converged:                    True
  Time: 0.08s

  VERDICT: Significant duality gap (RMSE = 0.5622)

Applications:

  • Network risk propagation — predict cascade failure thresholds
  • GNN regularization — duality defect as structural prior
  • Adversarial detection — perturbations that spike duality defect
  • Graph quality filtering — discard structurally inconsistent subgraphs

Status: CLI functional, undergoing validation on public network datasets (SNAP, NetworkX).

Meta-Dispatch

An AI orchestration layer that decomposes research tasks, routes sub-tasks to the most appropriate model, and assembles results with full traceability.

Features:

  • Static routing via config — no black-box decisions
  • Adversarial iteration — proposer/critic loop with convergence detection
  • @op protocol — models can trigger tools (diagnose, validate, archive)
  • Cost tracking — every call logged with token usage and latency
  • Fallback routing — automatic failover between API endpoints

Currently used internally at Apophenia. Open beta planned Q3 2026.

About

Apophenia is the tendency to perceive meaningful connections between unrelated things. It is a cognitive bias — but it is also the engine of pattern recognition and the origin of scientific hypothesis.

Our job is to determine which perceived connections are real.

Apophenia Pte. Ltd. is an AI-native research company based in Singapore. We work with research institutions, independent scientists, and technical teams who need to know whether a pattern is real — before they stake their work on it.
