## 先回答你的技术问题：4a 的部署方式

用 Claude Code 的本地 stdio MCP 服务器。理由三：

1. Illusion 是 Python，MCP SDK 的 stdio transport 是最简单、最不容易出错的接入方式。一个 `asyncio` 子进程跑 server，Claude Code 侧配一个 JSON config。不需要 HTTP、不需要鉴权层、不需要额外部署。
2. Schema 格式用 JSON Schema，定义在 server 的 `list_tools()` 返回里。具体定义两个 tool：
   - `propose_transforms`：输入 domain description + 已有变换列表 + 它们的 delta collapse 和 L3 verdict，返回 1-3 个新变换的自然语言描述
   - `search_literature`：输入 transform name + L1 model class，返回已知可判定性结果 + 引用
3. 不跑远程。不跑 Docker。你现在的机器跑 Illusion 和 MCP server 在同一台机器上，延迟为零，调试可以直接看 stdout。

这是唯一合理的起点。后续如果换成别的 MCP client，schema 不用变，只换 transport。
