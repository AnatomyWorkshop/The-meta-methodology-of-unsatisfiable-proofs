### 从全域闭包公理推导麦克斯韦方程（$U(1)$ 规范场）
#### 前提与符号定义
我们先明确全域闭包公理的核心形式：
$$\boxed{\mathcal{D}\phi = \star\,\mathcal{D}^{\dagger}\,\star\,\phi}$$
并补充推导所需的基础设定：
1. **时空流形**：4维闵氏时空（洛伦兹不变性，度规 $\eta_{\mu\nu} = \text{diag}(-1,1,1,1)$），满足连续极限（$\mathcal{D}$ 与 $\star$ 交换）。
2. **场的选择**：$U(1)$ 规范场对应的1-形式场 $\phi = A = A_\mu dx^\mu$（电磁势）。
3. **算子定义**：
   - 全导数算子 $\mathcal{D} = d + A \wedge$（外微分 $d$ + 规范导数，$U(1)$ 下规范势 $A$ 的耦合项）；
   - 自伴性 $\mathcal{D}^\dagger = \delta + \iota_A$（余微分 $\delta = -\star d \star$ + 内乘 $\iota_A$，保证可观测量谱为实）；
   - 霍奇对偶 $\star$：4维时空中1-形式 $\leftrightarrow$ 3-形式，满足 $\star\star = (-1)^{k(n-k)}$（$k$ 为形式阶数，$n=4$）。

#### 步骤1：简化公理（$U(1)$ 单粒子无荷极限）
无荷极限下规范导数退化为纯外微分（$A \wedge \phi \to 0$），公理简化为：
$$d\phi = \star \delta \star \phi$$
代入 $\phi = A$（1-形式），左侧为：
$$dA = \partial_\mu A_\nu dx^\mu \wedge dx^\nu = F_{\mu\nu} dx^\mu \wedge dx^\nu$$
其中 $F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu$ 是电磁场强张量（2-形式）。

#### 步骤2：计算右侧（霍奇对偶 + 余微分）
第一步：对1-形式 $A$ 取霍奇对偶，得到3-形式：
$$\star A = \frac{1}{3!} \epsilon_{\mu\nu\rho\sigma} A^\mu dx^\nu \wedge dx^\rho \wedge dx^\sigma$$
（$\epsilon_{\mu\nu\rho\sigma}$ 是4维全反对称张量，$\epsilon_{0123} = 1$）。

第二步：对3-形式 $\star A$ 取余微分 $\delta = -\star d \star$：
$$\delta \star A = -\star d \star \star A$$
利用霍奇对偶的自反性 $\star\star A = (-1)^{1\times3} A = -A$（4维时空1-形式的 $\star\star = -1$），化简得：
$$\delta \star A = -\star d (-A) = \star dA$$

第三步：再对 $\delta \star A$ 取霍奇对偶，得到右侧整体：
$$\star \delta \star A = \star (\star dA)$$
对2-形式 $dA$，霍奇对偶的自反性为 $\star\star dA = (-1)^{2\times2} dA = dA$，因此：
$$\star (\star dA) = dA$$

#### 步骤3：回代公理并导出麦克斯韦方程
将左右侧结果回代简化后的公理：
$$dA = \star \delta \star A \implies dA = \star (\star dA)$$
这是恒等式，需引入**源项**（荷电粒子的能动量耦合）才能得到非平凡的麦克斯韦方程：

1. **无源麦克斯韦方程**：对场强 $F = dA$ 取外微分，利用 $d^2 = 0$（外微分的幂零性）：
   $$dF = d(dA) = 0$$
   展开为分量形式：
   $$\partial_\lambda F_{\mu\nu} + \partial_\mu F_{\nu\lambda} + \partial_\nu F_{\lambda\mu} = 0$$
   对应经典无源麦克斯韦方程（如 $\nabla \cdot \mathbf{B} = 0$、$\nabla \times \mathbf{E} + \partial_t \mathbf{B} = 0$）。

2. **有源麦克斯韦方程**：引入电流1-形式 $J = J_\mu dx^\mu$，将公理扩展为包含源的形式（闭包要求"内部演化=外部约束"，源为外部约束）：
   $$\delta F = J$$
   利用 $\delta = -\star d \star$ 化简得：
   $$\star d \star F = -J$$
   展开为分量形式：
   $$\partial^\mu F_{\mu\nu} = J_\nu$$
   对应经典有源麦克斯韦方程（如 $\nabla \cdot \mathbf{E} = \rho$、$\nabla \times \mathbf{B} - \partial_t \mathbf{E} = \mathbf{j}$）。

#### 步骤4：恢复规范不变性
$U(1)$ 规范变换为 $A \to A + d\chi$（$\chi$ 为标量函数），代入场强得：
$$F' = d(A + d\chi) = dA + d^2\chi = dA = F$$
满足规范不变性——这是全域闭包公理"内部对称性→补偿场"推论的直接体现：$U(1)$ 内部对称强制产生补偿场 $A$，且场强在规范变换下不变。

### 关键说明（诚实的边界）
1. **推导的局限性**：
   - 上述推导是**半严格**的：我们假设了闵氏时空、$U(1)$ 规范群、无荷极限等前提，而非从公理"无假设"导出；
   - 源项 $J$ 的引入是"人为补充"，而非公理自动生成（全域闭包公理尚未能从内部导出荷电粒子的存在）；
   - 未涉及量子化（仅经典麦克斯韦方程），公理的量子力学极限（$\star=1$）需结合幺正性进一步推导。

2. **下一步可验证方向**：

3. **核心结论**：
