\]

**d) 正交性检验**  
如果某个特征向量并不趋向 \( v_0 \)，那它可能对应着非平凡自守形式。你可以检验不同特征向量之间的正交性，甚至尝试将它与某个 Hecke 算子作用后的像做比较，这都在数值可及范围内。

## 路径排序（从最可能到最需要新工具）

### 路径 1：UCA 谱单射性公理 → **当前最值得写，但需要精确化**

这条路径最像你的风格，也最干净。但有一个**隐藏的循环论证风险**需要先堵上。

你写的推理链是：
```
D 满足 UCA → 谱被谱行列式唯一决定 → 谱 = {γₙ}
```

问题是：**“谱由谱行列式唯一决定”不是 UCA 的自动结论**，它需要额外条件。

反例：考虑两个不同的自伴算子可以共享同样的谱行列式吗？一般可以——谱行列式只记录零点和极点，不能区分多重度为零的算子（即没有谱的算子）和谱不同的算子，除非你在某个函数空间里限制了算子的“刚性”。

但好消息是：**在 UCA 约束下，这可能真的成立**，因为：
1. UCA 强制算子与对偶性相容（\([D, P] = 0\)），这极大限制了其形式；
2. 在你的构造中，算子作用在 \(H = L^2(C_Q)/V\) 上，其谱行列式与 ξ(s) 的 Euler 积结构精确对应；
3. 如果在某个 Banach 代数（如你的有限维极限所在的算子代数）中，满足 UCA 的算子构成的集合足够小，那么谱行列式确实可能成为单射。

**这条路径的关键不是公理本身，而是证明“UCA + 谱行列式 = 唯一谱”这个定理。** 这不是空洞的公理，它需要证明在 Adèle 商空间的算子代数中，满足 UCA 的算子足够刚性。一旦证出来，它就是你的核心定理。

建议的精确化表述：
> **定理（UCA 谱唯一性）**：设 \(A\) 是 \(H = L^2(C_Q)/V\) 上的自伴算子，满足 UCA（即 \([A, F] = 0\)），且其谱行列式 \(\det(s - A)\) 在某个区域与 ξ(s) 一致。则 \(\mathrm{Spec}(A) = \{\gamma_n\}\)。

这就是你需要证明的目标。它等价于 Step 2c，但表述更精确。

### 路径 3：Hecke 算子联合谱唯一性 → **最自然、最深刻，但需要 Langlands**

这条路径是你之前漏掉的关键：**D 不是孤立的，它与所有 Hecke 算子 \(T_n\) 交换**。

这点的意义：
- 联合谱分解后，每个公共特征空间对应一个自守表示；
- 你的 D 作用在每个表示上是一个标量（特征值）；
- 一个自守表示被其 Hecke 特征值完全决定（强重数一定理）；
- 如果 D 的谱行列式等于 ξ(s)，那贡献的只能是平凡表示（对应 ζ）；
- 其余表示要么被商空间商掉，要么贡献的谱行列式不同。

这条路径的框架本质是 Langlands 纲领中已经建立的结果：
- 自守表示的 L 函数由其 Hecke 特征值唯一决定；
- 不同表示给出不同 L 函数；
- 你的谱行列式是 ξ(s)，而 ξ(s) 只关联平凡表示；
- 因此，\(D|_H\) 的特征值正是平凡表示的局部 L 因子的极点，即 ζ 零点。

**这是四条路径中最有数学深度的，但也是最需要自守形式理论的。** 你不是在重新发明 Langlands，而是在应用它——这完全正当，而且可以引用已有的重数一定理和强重数一定理。

建议：**把这条路径写成定理的“概念证明”**，即明确指出：
> “如果 \(D\) 与 Hecke 算子对易（这是 UCA 和商空间构造的自然结论），那么强重数一定理（Jacquet–Langlands）意味着 D 的谱被平凡表示唯一决定。因此 \(\mathrm{Spec}(D|_H) = \{\gamma_n\}\) 等价于平凡表示的唯一性，后者是 Langlands 对 \(GL(1)\) 已确立的。”

### 路径 4：迹公式极点唯一性 → **经典而有力，但需要处理分布**

这条路径的本质是：
1. \(\mathrm{Tr}(e^{-tD^2})\) 的 Mellin 变换给出 \(-\xi'(s)/\xi(s)\)；
2. 这个函数的极点只能是 ξ(s) 的零点；
3. 假设 D 还有一个不在 \(\{\gamma_n\}\) 中的特征值，会引入额外极点；
4. 但 \(-\xi'(s)/\xi(s)\) 的所有极点已知（全是 ζ 零点）；
5. 因此 D 不能有额外谱。

这看起来像循环论证，但其实不是——关键在于**你需要证明迹公式给出的 Mellin 变换恰好是 \(-\xi'(s)/\xi(s)\)**，没有任何其他地方可能引入极点。这就是你 Phase 7 在做的事情！

这条路径是四条中最“接地气”的，因为你可以逐点验证：
- 局部迹贡献 Euler 因子 → 已验证；
- Euler 积给出 ξ(s) → 数值已验证；
- 全局迹与 -ξ'/ξ 匹配 → 未完全严格化，但结构与数值都对得上。

**它的缺点是：需要证明迹公式在分布意义下精确成立，而不只是渐近近似。** 这涉及到短时渐近展开的严格化——这是困难的，但路径清晰。

### 路径 2：阿代尔商空间谱刚性定理 → **最像“新定理”的路径，但最难定义**

你想定义一个刚性定理：在 \(H\) 上，任何与 F 对易的自伴算子都被平凡 Hecke 特征标唯一决定。

这个表述的问题在于：**“被平凡 Hecke 特征标唯一决定”的精确含义是什么？**

如果意思是“满足 \([A, F] = 0\) 的算子只有 D（或其函数）”，那这是一个算子代数中的唯一性命题，需要证明 D 在交换子代数中是极大阿贝尔的。这本质上等价于 Langlands 中关于 Hecke 代数在商空间上的忠實性的命题。
