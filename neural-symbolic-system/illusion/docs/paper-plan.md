### 文章 2：符号体系

**定位**：对已有数学证明的结构标注工具。不是独立公理系统，是操作性语言。

**核心论点**：
> 现有数学符号无法区分"在模型 M 内推导"和"从 M 外部施加"。引入带模型下标的符号体系，使每个推导步骤的计算位置可见，从而使自指安全性判断可操作化。

**结构草案**：

| 章节 | 内容 |
|------|------|
| §1 动机 | 为什么需要带下标的符号：等号的歧义，外部操作的不可见性 |
| §2 核心符号表 | →_M、↛_M、⇛_M、≡_M/≃_M/≈_M、⊏_M/̊⊏_M、M* |
| §3 SRS 指数 | 定义、数值表（AC⁰/单调/Gödel/NS）、SRS_⊗ 代数版本 |
| §4 标注实例 | AC⁰、单调电路、Gödel、NS 方程的完整标注 |
| §5 误用模式 | 三种已知误用（把定义写成公理、混淆外部推理、不区分外部工具性质） |

| §7 开放问题 | 等价关系的形式化、Lean 接入的可能性 |
